# GxPlugins.lv2-aarch64

GxPlugins.lv2 is a set of extra standalone lv2 plugins designed to compliment the Guitarix project. GxP)lugin.lv2 written and maintained by [Hermann Brummer](https://github.com/brummer10).

This repository exists solely to provide a release point for the GxPlugin.lv2 package, pre-built for arm64. Installers for other platforms (currently amd64, and win64) can be 
downloaded [here](https://github.com/brummer10/GxPlugins.lv2/releases/tag/v1.0).

You can download a debian package for arm64 GxPlugin.lv2 here. 

To isntall the package, run 

    apt install ./gxplugins_1.0_arm64.deb


(Be careful to include the leading `./`). The Permission Denied warning at the end of the install is just a warming, and can be safely ignored.

Original sources for GxPlugins.lv2 are availabe at: https://github.com/brummer10/gxplugins.lv2
