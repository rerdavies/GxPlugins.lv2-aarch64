# GxPlugins.lv2-aarch64

GxPlugins.lv2 is a set of extra standalone lv2 plugins designed to compliment the Guitarix project. GxPlugins.lv2 is written and maintained by [Hermann Brummer](https://github.com/brummer10).

This repository exists solely to provide a release point for the GxPlugin.lv2 package, pre-built for arm64. Installers for other platforms (currently amd64, and win64) can be downloaded [here](https://github.com/brummer10/GxPlugins.lv2/releases/tag/v1.0).

You can download a GxPlugin.lv2 debian package pre-built for arm64  [here](https://github.com/rerdavies/GxPlugins.lv2-aarch64/releases/tag/v1.0).
